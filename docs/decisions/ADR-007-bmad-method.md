# ADR-007: BMAD Method as the delivery process

- **Status:** Accepted
- **Date:** 2026-09-23

## Decision

Use BMAD Method v6.12.0 (core + `bmm` module), installed with the official installer
(`npx bmad-method install --modules bmm --tools claude-code`) as Claude Code skills in
`.claude/skills/bmad-*`, with configuration in `_bmad/`.

Artifacts are kept inside `docs/`: planning (brief, PRD, UX, architecture, epics) in
`docs/planning/`, implementation (sprint status, stories, reviews) in `docs/stories/`, with
`docs/` as project knowledge.

## Consequences

- Vendored BMAD files are regenerated by the installer and must not be hand-edited; team
  customizations go in `_bmad/custom/config.toml`.
- BMAD skills call helper scripts with `uv run`. The scripts are stdlib-only, so `python` works
  until `uv` is installed.
