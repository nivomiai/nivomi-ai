# Requirements matrix

Traceability from the [PRD](prds/prd-Nivomi-2026-09-26/prd.md) (revision 3) to architecture, code
and tests. Updated at the end of each implementation phase; this version reflects **Phase 1
(platform foundation), Phase 2 (leads and imports) and HubSpot inbound ingestion, 2026-09-27**. The phase plan is in
[implementation-plan.md](implementation-plan.md).

**Status legend**

| Status                | Meaning                                                                                   |
| --------------------- | ----------------------------------------------------------------------------------------- |
| IMPLEMENTED           | Built, tested, and meets the PRD requirement as written                                   |
| PARTIALLY IMPLEMENTED | Some of the requirement is built and tested; the gap is stated                            |
| BLOCKED               | Cannot proceed without something external: provider accounts, credentials, owner decision |
| NOT STARTED           | Scheduled for a later phase; nothing built yet (added to the four statuses in the brief)  |
| NOT APPLICABLE        | Does not apply to this product or phase                                                   |

Paths: `api/` = `apps/api/src/`, `web/` = `apps/web/`, `db/` = `packages/database/src/schema/`,
`it/` = `apps/api/test/integration/`.
